# Математический помощник (Pix2Text + SymPy)

Приложение для распознавания и вычисления математических выражений с изображений.

## 🚀 Возможности

- 📸 Загрузка изображения с формулой
- 🤖 Распознавание формул (Pix2Text)
- 🧮 Вычисление выражений (SymPy)
- ➕ Поддержка:
  - арифметики
  - уравнений
  - тригонометрии (sin, cos, tan)
  - интегралов
- 💅 Удобный графический интерфейс (Tkinter)

---

## 🛠 Используемые технологии

- Python
- Tkinter (интерфейс)
- Pix2Text (распознавание формул)
- SymPy (математические вычисления)
- Pillow (работа с изображениями)

---

## ▶️ Установка

```
git clone https://github.com/ТВОЙ_НИК/math-assistant-pix2text.git
cd math-assistant-pix2text

python -m venv .venv
.venv\Scripts\activate

pip install pillow sympy pix2text ```
